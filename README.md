# Dar Transit App

A transit helper application focused on Dar es Salaam, built with modern web technologies and AI features.

## Features

- Designed specifically for Dar es Salaam transit needs
- Clean and intuitive interface
- AI-powered features
- Built with TypeScript for better reliability
- Fast development setup with Vite

## Tech Stack

- TypeScript
- Vite
- HTML / CSS
- AI integration

## Getting Started

```bash
git clone https://github.com/mussaissack363-alt/dar-Transit-App.git
cd dar-Transit-App
npm install
npm run dev
